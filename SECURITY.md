# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities as public GitHub issues.

Use GitHub's private vulnerability reporting for this repository:

https://github.com/Willi-28/open-clocktower/security/advisories/new

Include a short description, affected version or commit if known, reproduction steps, impact, and any suggested fix. Do not include room codes, secrets, private notes, uploaded private character packs, or credentials unless they are essential to the report.
