# Deployment

## Traefik Production

Production uses one app container behind Traefik and one internal PostgreSQL
container. Traefik owns HTTPS and forwards normal HTTP and WebSocket traffic to
the app container on port `8000`.

Assumptions:

- Traefik already runs on the homeserver.
- Traefik owns ports `80` and `443`.
- The DNS record `botc.meine-domain.de` points to the homeserver.
- Traefik has a certificate resolver named `letsencrypt`.
- Traefik exposes an external Docker network named `traefik_proxy`.

Required environment values:

- `APP_DOMAIN`, for example `botc.meine-domain.de`
- `POSTGRES_DB`
- `POSTGRES_USER`
- `POSTGRES_PASSWORD`
- `ICE_SERVERS_JSON`
- `TRAEFIK_CERT_RESOLVER`

Persist these volumes:

- `postgres_data:/var/lib/postgresql/data`
- `open_clocktower_data:/app/data` for uploads and future local assets

The production compose file expects an existing external Docker network named
`traefik_proxy`:

```bash
docker network create traefik_proxy
cp .env.production.example .env
docker compose -f docker-compose.prod.yml pull
docker compose -f docker-compose.prod.yml up -d
```

Set at least these values in `.env` before the first start:

```env
APP_DOMAIN=botc.meine-domain.de
TRAEFIK_CERT_RESOLVER=letsencrypt
POSTGRES_PASSWORD=change-this-password
```

`docker-compose.prod.yml` builds `DATABASE_URL` from the PostgreSQL variables, so
do not commit a production `.env`. Use `OPEN_CLOCKTOWER_IMAGE` to choose the
published image tag, for example `willi28/open-clocktower:0.3`.

The production compose file defaults `FORCE_HTTPS=true`. Plain HTTP traffic on
Traefik's `web` entrypoint is redirected to HTTPS, and the backend also rejects
accidental direct HTTP access.

Run exactly one app container for version `0.1`. Rooms, timers, WebSocket
connections, and voice signaling live in process memory, so multiple app
containers would split players across different room states.

## Voice Chat

Browsers need ICE servers for WebRTC voice. The default `.env.example` uses public
STUN only:

```env
ICE_SERVERS_JSON=[{"urls":"stun:stun.l.google.com:19302"}]
```

For reliable production voice, add a TURN server:

```env
ICE_SERVERS_JSON=[{"urls":"stun:stun.l.google.com:19302"},{"urls":"turn:turn.example.com:3478","username":"turn-user","credential":"turn-password"}]
```

Keep TURN credentials out of git. For a public instance, prefer short-lived TURN
credentials generated by a small server-side credential endpoint.
